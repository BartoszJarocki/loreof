# Prior art I reviewed on 2026-11-03

I understated the history tools that already exist. Playing a repository in the browser isn't new.
What I kept is the combination of co-change placement, playback through time, and captions tied to
commit evidence.

| Project                                                                                                            | Verified behavior                                                                | Implication for Lore                                                        |
| ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| [Gource](https://gource.io/) and its [controls](https://github.com/acaudwell/Gource/wiki/Controls)                 | Animated repository history, activity-following cameras, and caption files       | Don't claim that animated history or captions are unique.                   |
| [Git Truck](https://github.com/git-truck/git-truck)                                                                | Local interactive repository structure, commit activity, authorship, and history | The original plan's claim that Git Truck has no time dimension is wrong.    |
| [Gource View](https://github.com/schlunsen/gource-view)                                                            | Repository history in the browser with a moving camera and MP4 export            | Browser delivery and export already have direct competition.                |
| [CodeSee acquisition announcement](https://gitkraken.com/press/gitkraken-acquires-codesee-launches-devex-platform) | GitKraken announced the acquisition on 2024-05-14                                | An acquisition doesn't prove demand for Lore's proposed paid weekly digest. |

The business checks are still experiments. I haven't treated any visitor, signup, interview, or
willingness-to-pay target as reached.

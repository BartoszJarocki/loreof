# Prior art reviewed on 2026-11-03

The original comparison understated existing history tools. Lore's distinction is a specific combination of co-change placement, time playback, and captions tied to commit evidence. Browser playback alone is not new.

| Project                                                                                                            | Verified behavior                                                                | Implication for Lore                                                            |
| ------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| [Gource](https://gource.io/) and its [controls](https://github.com/acaudwell/Gource/wiki/Controls)                 | Animated repository history, activity-following cameras, and caption files       | Do not claim that animated history or captions are unique.                      |
| [Git Truck](https://github.com/git-truck/git-truck)                                                                | Local interactive repository structure, commit activity, authorship, and history | The original plan's claim that Git Truck has no time dimension is incorrect.    |
| [Gource View](https://github.com/schlunsen/gource-view)                                                            | Repository history in the browser with a moving camera and MP4 export            | Browser delivery and export already have direct competition.                    |
| [CodeSee acquisition announcement](https://gitkraken.com/press/gitkraken-acquires-codesee-launches-devex-platform) | GitKraken announced the acquisition on 2024-05-14                                | Acquisition alone does not prove demand for Lore's proposed paid weekly digest. |

The business validation steps remain experiments. No visitor, signup, interview, or willingness-to-pay target has been claimed as achieved.

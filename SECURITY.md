# Security policy

## Report a vulnerability

Report it privately, through GitHub's private vulnerability reporting on this repository, or by
email to bartosz@jarocki.me. Don't open a public issue.

Tell me what you did, what happened, and the smallest reproduction you can give. If the report
involves someone else's data, don't put that data in a public place.

## Scope

This policy covers the source in this repository and the live service at https://loreof.vercel.app.
That includes the API routes, the repository page, the share image, and the storage and admission
limits behind them.

Cost abuse is in scope. If you can make Lore spend model budget, Blob storage, Sandbox time, or
Redis capacity past the documented limits, report it the same way.

Reports about third-party services, including GitHub, Vercel, Upstash, and AI Gateway, belong with
those providers.

## What to expect

I'll acknowledge the report, look into it, and tell you what I found. I'll credit you in the fix if
you want that. I won't publish the details before a fix is out.

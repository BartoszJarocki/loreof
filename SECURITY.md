# Security policy

## Report a vulnerability

Report privately through GitHub's private vulnerability reporting on this repository, or email
bartosz@jarocki.me. Do not open a public issue.

Include what you did, what happened, and the smallest reproduction you can give. If a report involves
another person's data, do not include it in a public place.

## Scope

This policy covers the source in this repository and the live service at
https://loreof.vercel.app. It includes the API routes, the repository page, the share image, and the
storage and admission limits behind them.

Cost abuse counts as a security issue. If you can make Lore spend model budget, Blob storage, Sandbox
time, or Redis capacity beyond the documented limits, report it the same way.

Reports about third-party services, including GitHub, Vercel, Upstash, and AI Gateway, belong with
those providers.

## What to expect

We will acknowledge a report, investigate it, and tell you what we found. We will credit you in the
fix if you want, and we will not publish details before a fix is available.
